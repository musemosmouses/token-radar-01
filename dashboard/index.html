Token Launch Radar

Pre-token protocols ranked by an implied value fitted from the snapshot’s own traded tokens. The watchlist is the floor, never the ceiling: the board carries the 40 watchlist protocols and the 158 early finds below it.

implied = 102.71 × TVL0.56 × momentum × seasoning (×0.5 when a related token already trades)

How a row is valued. The size curve is an OLS fit of log market cap on log TVL over 84 comparable traded protocols (R² 0.22). Momentum scales the curve by the protocol’s 7-day TVL change; seasoning scales it by how long the protocol has run with no token recorded. No protocol name is ever special-cased: the same function scores every row, and the sandbox on the calibration tab runs that same function. Leave-one-out backtest on the comparables: typical miss ×2.61, against ×4.17 for a flat multiple. The middle half of backtest errors is ×0.43–×3.84 and is shown per row as its range.

An implied value is this radar’s own claim, never make.fun’s. “Records no token” is DefiLlama’s record, not proof a token does not exist. The farm slice assumes 10% of the implied value reaches depositors, shared pro-rata over TVL; gas is six transactions priced by the protocol’s first chain. Nothing here predicts whether or when a token is issued.
